新建

导入 AI 记忆 / 外部 Context

把 GPT 记忆、Claude Context、或其他 AI 的设定粘贴进来。每行一条；若含「： / : / — / -」会自动拆成「标题｜内容」；也支持直接粘贴 JSON 数组。导入后统一打上「外部导入」标签，不覆盖你已有的条目。

☁ 云端同步设置

开启后，数据与 Supabase 云端同步，电脑 / 手机 / 未来团队看同一份。需先建一个免费的 Supabase 项目并建表（步骤见下）。

✅ 你的项目 URL 与发布密钥已预填并启用。还差一步：在 Supabase → SQL Editor 执行下面建表 SQL（粘贴 Run 即可），之后刷新工作台即自动同步。

建表 SQL：
create table yaqi_workbench (
  id text primary key,
  state text,
  updated_at timestamptz default now()
);
并开启该表的「Row Level Security」后给 anon 角色增删改权限（或用 Service Key —— 仅自用推荐前者）。
