# 雅祺的事业工作台 (V1)

一个**单文件、本地优先、可云端同步**的个人事业工作台，面向「艺术疗愈师 × 教育人 × AI 创作者」的真实工作流。

> 核心目标：让我每天真正用起来，降低工作混乱、信息分散和重复劳动；同时可作为未来 AI 教学 / 青少年教育的真实案例。

## 在线访问

🌐 https://zengyaqi2025-boop.github.io/yaqi-workbench/

（手机竖屏、电脑横屏都可用；顶部 ☰ 打开导航抽屉。）

## 模块

- **今日指挥台**：首页。今日 TOP3 + 五态任务聚合（今天必须 / 即将 / 可推进 / 等待 / 已完成），每张卡带「下一步行动」+「处理」按钮。
- **内容运营中心**：一源多发流水线（灵感→选题→创作中→待发布→已发布→数据→复盘→可复用）+ 获客转化数据驾驶舱（小红书 / 视频号双平台）。
- **课程·学员中心**：学员成长档案。
- **艺术作品中心**：作品档案与状态流。
- **项目·事业运营**：下一步行动必填。
- **写书**：章节 + 收入书稿素材。
- **知识库**：底座，一份信息只存一次；支持「导入 AI 记忆」（粘贴 GPT / Claude 等外部设定批量导入）。
- **AI 助手中心**：4 个入口（内容主编 / 教学助理 / 项目管家 / 艺术策展助手）—— 即数字员工在工作台里的调用点。

## 数据存储

- **默认本地**：数据存在浏览器 `localStorage`，离线可用。用「导出备份」存一份 JSON 当 master 副本。
- **云端同步（可选）**：顶栏「☁ 同步」填入 Supabase 项目信息后，电脑 / 手机 / 团队看同一份。详见下方「接入云端同步」。

## 本地使用

直接双击 `workbench.html` 用浏览器打开即可。日常增删改都在界面内完成。

## 接入云端同步（Supabase，免费）

1. 打开 https://supabase.com 注册（免费版 Free tier，无需信用卡）。
2. 新建一个 Project，等待初始化完成。
3. 左侧 **SQL Editor** → 新建查询 → 粘贴仓库里的 `supabase-setup.sql` 全部内容 → **Run**。
4. 左侧 **Project Settings → API**，复制：
   - `Project URL`（形如 `https://xxxx.supabase.co`）
   - `anon public` / `publishable` 密钥（新版为 `sb_publishable_` 开头；老版为 `eyJ` 开头）
5. 打开工作台顶栏「☁ 同步」→ 勾选启用 → 填入 URL / anon 密钥 / 表名（默认 `yaqi_workbench`）→ 点「测试并保存」→「立即同步」。

配置完成后，任意设备打开同一网址都会自动拉取同一份数据。

## 更新与部署

本仓库即 GitHub Pages 源。修改后：

```
git add -A
git commit -m "更新工作台"
git push
```

GitHub Pages 会自动重新发布（通常 1 分钟内生效）。

## 安全提示

- 云端同步表对 `anon` 角色开放读写，因此「项目 URL + anon key」等同于数据访问凭证，请勿公开泄露。
- 工作台目前是「单人编辑 / 多端查看」模型。若需多人**同时**编辑并区分权限，请接入 Supabase Auth。
- 财务相关请勿放入本工作台（按规划独立为「私密财务驾驶舱」）。
